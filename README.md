# Krishna Nitesh Chunduru — Developer Portfolio

A responsive React + Vite portfolio inspired by the supplied reference: grayscale/black split hero, compact navigation, spacious typography, editorial section labels, skills grid, portfolio gallery, and minimal contact footer. The visual direction is customized for software recruitment with a lime accent and original CSS-built 3D orb/orbit artwork.

## Run locally

1. Install Node.js (LTS recommended).
2. Extract this folder and open a terminal in it.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite.

## Production build

Run `npm run build`. The generated site is in `dist/`.

## Customize before applying

- Verify the internship dates and project descriptions.
- Add a PDF resume to `public/` if you want a resume download link.
- If desired, add your own portrait; the hero currently uses custom animated 3D CSS artwork instead of a stock headshot.
- Keep all project performance percentages off the website unless you can explain how they were measured. This portfolio intentionally avoids unsupported percentage claims.
- Project GitHub links point to the repositories listed in the provided resume.

## Deploy

Import the folder/repository into Vercel or Netlify. Build command: `npm run build`; output directory: `dist`.
